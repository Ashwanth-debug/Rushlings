# Claude Code Milestone Session Template

Use this prompt to start a fresh Claude Code session for a milestone.

---

Read `CLAUDE.md`, `docs/GAME_DESIGN.md`, `docs/ROADMAP.md`, and `docs/DECISIONS.md` in full.

We are working on **Milestone [NUMBER] — [NAME]** only.

Do not implement anything yet.

First:
1. Inspect the current Git status and project structure.
2. Inspect the implementation produced by previous milestones that affects this milestone.
3. Confirm the current milestone status from `docs/ROADMAP.md`.
4. Produce a detailed implementation plan for this milestone.

Your plan must include:
- Goal and risk being tested.
- Exact user-visible/playable outcome.
- Proposed Godot scene/node/script structure.
- Files you expect to create/change.
- Input/control behavior.
- State/data model if relevant.
- Bot/network implications if relevant.
- How you will test using Godot MCP.
- Human playtest steps.
- Acceptance criteria copied/adapted from the roadmap.
- Technical risks or ambiguities.
- Explicit out-of-scope list.
- Recommended checkpoint/commit strategy.

Do not silently resolve game-design ambiguity. If a decision would change the game, list it as a question/recommendation.

Keep the implementation as small as possible while satisfying the milestone.

Wait for my approval before implementing.
